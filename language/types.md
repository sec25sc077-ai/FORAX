# FORAX Data Types v0.1

Primitive types:
- STRING
- INTEGER
- FLOAT
- BOOLEAN
- TIMESTAMP

Forensic types:
- IP_ADDRESS
- MAC_ADDRESS
- PORT
- PROCESS
- FILE
- USER
- DEVICE
- NETWORK_CONNECTION
- PACKET
- FLOW
- PCAP
- HASH
- EVIDENCE
- TIMELINE
- REPORT

Collections are represented as TYPE[].

The compiler must reject incompatible comparisons and unknown fields.
